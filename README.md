# PokePlant

Starter gratuit Expo / React Native pour un pokedex de plantes.

## Stack
- Expo
- React Native
- TypeScript
- Navigation native

## Dossier
```txt
PokePlant/
├─ assets/
├─ src/
│  ├─ components/
│  ├─ context/
│  ├─ data/
│  ├─ navigation/
│  ├─ screens/
│  ├─ theme/
│  ├─ types/
│  └─ utils/
├─ App.tsx
├─ app.json
├─ babel.config.js
├─ package.json
└─ tsconfig.json
```

## Lancer le projet
```bash
npm install
npm start
```

Puis ouvre Expo Go sur ton téléphone et scanne le QR code.

## Écrans inclus
- Accueil
- Détail d'une plante
- Favoris
- Réglages

## Notes
- Les favoris sont en mémoire pour garder le starter simple et gratuit.
- Les données de plantes sont locales dans `src/data/plants.ts`.
